# Next.js SSR

Example [Next.js](https://nextjs.org/) app with server-side rendering (SSR). Next.js is a React framework for building full-stack web applications.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Railpack |
| Project directory | `/` |
| Install command | leave empty |
| Build command | leave empty |
| Start command | leave empty |
| Application port | `3000` |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
npm install

# run in development mode with watch
npm run dev

# build and run for production
npm run build
npm run start
```

Requires Node.js 20.9 or later.
